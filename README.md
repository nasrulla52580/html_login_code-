# ئۇيغۇرچە Neumorphism كىرىش ۋە تىزىملىتىش كۆرۈنمە يۈزى (Modern Uyghur Neumorphic UI)

زامانىۋى Neumorphism (Soft UI) ئۇسلۇبىدا لاھىيەلەنگەن، تولۇق RTL (ئوڭدىن سولغا) قوللايدىغان ھەم كومپيۇتېر ۋە كۆچمە تېلېفونلارغا 100% ماسلاشقان كىرىش ۋە تىزىملىتىش كۆرۈنمە يۈزى.

---

## ئالاھىدىلىكلىرى (Features)

- ✨ **Neumorphism (Soft UI) لاھىيەسى**: نەپىس ئىچكى-تاشقى كۆلەڭگە ۋە سىلىق نۇر قىرلىرى.
- 🔄 **3D پىرقىراش (3D Flip & Spin Animation)**: كىرىش ۋە تىزىملىتىش ئوتتۇرىسىدا سىلىق 3D ئالمىشىش.
- 🪶 **لەيلىمە خەت قەۋىتى (Floating Labels)**: كۆزنەك تاللانغاندا خەتنىڭ سۈزۈك، تولۇق ھەم تەبىئىي ئۈستىگە كۆتۈرۈلۈشى (ئۇيغۇرچە چېكىتلەر ۋە ھەرپلەر 100% تولۇق چىقىدۇ).
- 📱 **تولۇق ماسلىشىشچان (Fully Responsive)**: كۆچمە تېلېفون (`100dvh`) ۋە كومپيۇتېرلاردا تولۇق كۆرۈنۈش كاپالىتى.
- ⚡ **تەبىئىي كىچىك بەلگىلەر ھەرىكىتى**: كىرگۈزۈش بەلگىلىرى تاللانغاندا نەپىس لەرزان مىدىرلايدۇ، نورمالدا ئارتۇق مىدىرلىمايدۇ.
- 🛡️ **پارول كۆرسىتىش/يوشۇرۇش**: بىخەتەرلىك ۋە قوللىنىشچانلىق تەڭپۇڭلاشتۇرۇلغان.
- 🌐 **تەمىنلەنگەن مۇلازىمېتىر (`server.js`)**: Node.js ئارقىلىق بىر كۇنۇپكا بىلەن يەرلىكتە قوزغىتىش.

---

## ئىشلىتىش ئۇسۇلى (Quick Start)

### 1. بىۋاسىتە ئېچىش:
`index.html` ھۆججىتىنى ھەرقانداق زامانىۋى تور كۆرگۈچ (Chrome, Edge, Safari, Firefox) ئارقىلىق ئاچسىڭىزلا بولىدۇ.

### 2. Node.js مۇلازىمېتىرى ئارقىلىق قوزغىتىش:
```bash
node server.js
```
تور كۆرگۈچىڭىزدىن `http://localhost:3001` ئادرېسىغا كىرىڭ.

---

## تېخنىكىلار (Tech Stack)

- **HTML5** (Semantics & Accessible RTL Markup)
- **CSS3** (Neumorphism, Modern Flexbox, CSS Variables, 3D Transforms)
- **Vanilla JavaScript** (Zero external dependencies)
- **Font Awesome 6** (Modern Vector Icons)
- **Google Fonts** (Noto Sans Arabic)
